# portfolio-assets

Media for the John Greg portfolio site (john-greg-preview.vercel.app), served through jsDelivr.
This branch holds only these files and is not part of the app.

- `mirror-card.mp4`: Mirror project card, 720x540, 5 s, H.264, no audio
- `mirror-card.jpg`: its first frame, used as the poster
- `vanragedon-card.mp4`: Vanragedon Circuit card, 768x480, 8 s seamless loop, H.264, no audio
- `vanragedon-card.jpg`: its first frame, used as the poster
- `cards/chambasuave-tarjeta-loop.mp4`: chambasuave card, 768x480, 10 s seamless loop, H.264, no audio
- `cards/chambasuave-tarjeta.webp`: its first frame, 1280x800, used as the poster
